# Microproject – Basic Web Designing

This is my first major frontend project built using pure HTML and CSS only.

It was created as a college microproject for the subject **Basic Web Designing**, and it helped me improve my understanding of frontend development fundamentals.

## 🚀 Live Demo

🔗 Live Website: https://rayanshk9.github.io/Microproject/

## 📌 Project Overview

This project is a multi-section responsive website designed using only:

- HTML5
- CSS3

No frameworks, no JavaScript — only pure frontend fundamentals.

The goal of this project was to strengthen my basics in:

- Page structure
- Layout design
- CSS styling
- Positioning and alignment
- Responsive design
- UI improvement using animations and hover effects

## ✨ Features

- Clean and modern UI
- Multiple website sections
- CSS animations
- Hover effects
- Structured layout design
- Responsive styling basics
- Live deployment using GitHub Pages

## 🛠 Technologies Used

- HTML5
- CSS3
- GitHub Pages (for deployment)

## 📚 What I Learned

While building this project, I learned:

- How real websites are structured
- Better CSS styling practices
- Layout management
- Importance of spacing and alignment
- Hosting projects using GitHub Pages
- Improving UI using animations
